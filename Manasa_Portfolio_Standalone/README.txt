MANASA PAGADALU — STANDALONE PORTFOLIO

Open index.html in your browser. No installation or build step is needed.
Keep index.html, styles.css, script.js, and the assets folder together.
Upload this folder to any static website host to publish it.

Edit content in index.html; project dialog details are in script.js.
Edit colors and animations in styles.css.
Replace assets/manasa-portrait.jpeg to change the photo.
The contact form opens your email app; it does not send or store messages itself.
Google Fonts requires internet access; the page uses system font fallbacks offline.
